## 🚀 Featured Projects

### 🛒 [Olist E-Commerce Analytics Project (SQL + Power BI)](sql-olist-ecommerce-project/)
- **Description:** An end-to-end analytics project on the Olist Brazilian E-Commerce dataset (~100K orders). Covered database architecture in SQL Server (`BULK INSERT`), 8-step EDA, data cleaning (handling 814 duplicate reviews), RFM customer segmentation, and an interactive executive Power BI dashboard with full visual documentation.
- **Tech Stack:** SQL Server (T-SQL), Power BI (DAX, Power Query), Star Schema Modeling.
- **Key Highlights:** Built custom SQL views in a `gold` schema, engineered an RFM customer model, and visualized key insights demonstrating how delivery delays severely impact customer satisfaction scores (~40% score drop).

### 💳 [Credit Risk Analytics Project (SQL + Power BI)](credit-risk-analytics-project/)
- **Description:** An end-to-end analytics project on loan default risk. Joined loan and borrower tables in SQL Server, ran an 8-step EDA to segment borrowers into risk brackets (credit score, DTI ratio, loan purpose, employment status and tenure), and presented the results in an interactive Power BI dashboard.
- **Tech Stack:** SQL Server (T-SQL), Power BI, `CASE` Bucketing, CTEs, Joins & Aggregations.
- **Key Highlights:** Against a 24% portfolio default rate, identified the main risk drivers: credit scores of 520–599 (49.14% default rate), DTI above 40% (23.71% and 34.32% in the top two brackets), and employment tenure under 2 years (34.52%). Also showed that loan size alone does not separate defaulted from non-defaulted loans.

### 📊 [Data Professional Survey Dashboard](powerbi-data-professional-survey/)

- **Tech Stack:** Power BI, Power Query, DAX, Data Modeling.
- **Key Highlights:** Cleaned raw survey data, structured relationships, built custom dynamic DAX measures (Average Salary, Age, Work/Life Balance, and dynamic Gauge boundaries), and designed an interactive dashboard with cross-filtering across countries and programming languages.
